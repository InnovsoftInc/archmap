# Architecture

What this system is made of and how the parts connect. This folder is the
architecture map: one markdown file per service, endpoint, job, table, enum,
role and flow, kept up to date by an AI agent as the code changes.

Replace this paragraph with a short overview of the system: what it does, who
uses it, and the few pieces everything else hangs off.

## Keeping it current

Ask your agent to run the `brief` command from the `AGENTS.md` section, follow
it, then run `check` until it passes. CI runs `check` on every pull request.
